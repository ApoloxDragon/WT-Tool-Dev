# WT Session Readout — Documentation

Welcome. **WT Session Readout** turns the match logs you copy out of War Thunder into clear numbers: win rate, Silver Lions (SL), Research Points (RP), what you are researching, and how many matches a goal will take. Everything runs inside your web browser — nothing is uploaded anywhere.

> This is the **Development** version of the site. It is where new things are tried before they reach the stable release, so things can change. The documentation describes how this version works today.
