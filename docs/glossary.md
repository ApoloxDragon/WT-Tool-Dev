# Glossary

**Analyze** — the button that reads the pasted text and fills in the results (and saves matches to the archive).

**Archive** — your saved matches, kept compressed in this browser. The Advanced view reads it.

**Battle type / category** — the group a match is placed in, from its mode name (for example *Random Battles*, *Tank Assault*, or one of your own rules).

**Bottleneck** — in the goal calculator, whichever goal (RP or SL) needs more matches; labelled *RP-bound*, *SL-bound* or *tied*.

**Booster** — the +30% RP bonus; the toggle multiplies expected RP by 1.3.

**CRP** — the RP figure the site counts for a match (see *Reading your logs*).

**Contrast ratio** — how clearly one colour reads on another. 4.5:1 is good; under 3:1 is refused.

**Dedupe / duplicate** — a repeated match (same Session ID); struck through and excluded from totals.

**Detail (●) / summary-only (○)** — whether a match has its full original text stored (●) or only a summary (○).

**Dev / stable** — the in-progress version of the site (this one) and the released one.

**Export Raw** — the lossless backup of your archive's original match text.

**IndexedDB** — the browser database the archive lives in.

**Minimal export** — a compact summary-only file for carrying totals between sessions.

**Net SL** — Silver Lions earned in a match after costs.

**Other RP** — RP that went to modules and research progress rather than a new vehicle.

**Preset** — a saved set of nine colours (plus font and size). Eight come built in; you can save your own.

**Research target** — a vehicle you were unlocking; "RP by research target" totals RP toward each.

**RP / SL** — Research Points / Silver Lions, War Thunder's research and money currencies.

**Service worker** — the browser feature that lets the site cache itself for offline use and instant return visits.

**Session ID** — the unique code on every match report, used to avoid counting a match twice.

**Swatch** — a small colour button in the top bar that applies a preset.

## More terms

**Activity** — the activity percentage the game reports for a match or vehicle; shown in the Advanced view.

**Backup vehicle / damaged** — tags the Advanced view shows next to a vehicle when the log flags it that way.

**Earned SL** — SL a match paid before costs (net SL subtracts costs).

**Event type** — the kind of scoring event (an award, a kill, and so on) in a match's breakdown.

**Play RP / Skill bonus RP** — RP columns in the vehicle table: RP for time played, and RP from a skill bonus.

**Rollup** — a small per-match summary saved with each archived match so the Advanced view and its insights open quickly.

**Rule (battle-type rule)** — a keyword and a label that place a match into a category.

**Current session** — what is in the paste box plus imported summaries; the opposite of the archive.
