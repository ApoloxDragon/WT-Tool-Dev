# Insights explained

The **Insights** section in the Advanced view adds up your whole archive. It has three collapsible tables. The heading shows the scope, for example *— 67 matches, 67 with stored detail*.

## By map
One row per **map** (the mission name), most-played first.

| Column | Meaning |
|---|---|
| **Map** | The mission name |
| **Matches** | How many matches you played on it |
| **Win%** | Share of those matches you won |
| **Avg SL** | Average net SL per match on that map |
| **Avg RP** | Average RP per match on that map |

This table uses **every** archived match, including summary-only ones.

Use it to see whether some maps are consistently better or worse for you. Small counts (one or two matches) are noise — look at maps you have played several times.

## By vehicle
Only matches with **stored detail** (●) are included. Rows are sorted by time played.

| Column | Meaning |
|---|---|
| **Vehicle** | Vehicle name |
| **Matches** | Matches in which you actually played it (spawned-but-never-played entries aren't counted) |
| **Time played** | Total time on it |
| **Avg activity** | Average activity percentage over those matches |
| **Play RP** | Total play RP on it |
| **Kills** | Total kills credited to it |

Use it to see which vehicles you really spend time in and which earn well.

## Earnings by event type
Also from matches with stored detail. Sorted by SL.

| Column | Meaning |
|---|---|
| **Event type** | The kind of scoring event |
| **Events** | How many happened |
| **SL / RP** | Total SL and RP they earned |

This shows what actually earns for you — for example whether kills, assists or other awards dominate.

## When the tables fill in
The By-map table is shown straight away. The vehicle and event tables fill in **when you open their section**, and they read small per-match summaries saved with each match, so they are quick even for large archives. If you have older matches saved before those summaries existed, the first open prepares them once (a progress message is shown); after that it is instant.

## What the tables do not do
- They always cover the **whole archive**, not the current filter.
- Summary-only matches (○) appear in the map table but not the vehicle or event tables.
- They are totals and averages, not trends over time.

## Making them more useful
- Keep logs coming in regularly so the numbers settle.
- Import raw exports (not minimal ones) so detail isn't lost.
- Compare maps only after several matches each.
